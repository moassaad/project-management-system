### Added (Sprint 002)
- [BE-S002-01] Establish backend structure and environment profiles — `config/`, `common/`, `api/` packages (package-info) + `application-dev.yml` / `application-test.yml` placeholders (no datasource/domain)
- [BE-S002-02] Configure PostgreSQL datasource and Docker Compose — `org.postgresql:postgresql` (runtime), `docker-compose.yml` (`postgres:16-alpine`, `pms-db`, `5432:5432`), `spring.datasource` (`SPRING_DATASOURCE_*` placeholders, Hikari) + README docs
- [BE-S002-04] Add Bean Validation foundation — `spring-boot-starter-validation` (Jakarta Validation 3.x, Hibernate Validator 9.1.3), sample DTO `@NotBlank`/`@Size` with `MockMvc` standalone + direct `Validator` tests verifying `MethodArgumentNotValidException` → 400 (no custom Problem Details yet, deferred to BE-S002-05)
- [BE-S002-05] Implement RFC 9457 Problem Details error handling — `GlobalExceptionHandler` (`@RestControllerAdvice`) with `ProblemDetail` (`type` `https://api.example.com/problems/...`, `title`, `status`, `detail`, `instance`, `errors: [{detail, pointer: \"#/field\"}]`): `MethodArgumentNotValidException` → 422, `ConstraintViolationException` → 400, `ResourceNotFoundException` → 404, generic `Exception` → 500; all `application/problem+json`, no stack/DB/class exposure
- [BE-S002-03] Introduce JPA, Flyway, and UUID base entity — `spring-boot-starter-data-jpa`, `flyway-core`, `flyway-database-postgresql`, `V1__baseline.sql` (pgcrypto comment baseline, no domain tables), `spring.jpa.hibernate.ddl-auto=validate`, `open-in-view=false`, `flyway.enabled/locations`, `BaseEntity` (`@MappedSuperclass`, `@Id UUID @GeneratedValue @UuidGenerator`, `@CreationTimestamp createdAt`, `@UpdateTimestamp updatedAt`), H2 `src/test/resources/application.yml` for `verify` without Docker
- [BE-S002-06] Establish API /api/v1 foundation with health endpoint — `HealthController` `@RequestMapping(\"/api/v1\")` `GET /health` → `{\"data\":{\"status\":\"UP\"}}` `application/json` (no auth, no Problem Details for success), `CorsConfig` `http://localhost:5173` `allowCredentials:true` `GET/POST/PATCH/DELETE` temporary (Sprint 013 hardens), `GlobalExceptionHandler` extended for `NoResourceFoundException`/`NoHandlerFoundException` → 404 `application/problem+json`
- [BE-S002-07] Configure OpenAPI generation and export — verified `org.springdoc:springdoc-openapi-starter-webmvc-ui:3.1.1` compatible with `spring-boot-starter-parent:4.1.1` (2.8.x for Boot 3, 3.x for Boot 4, Jakarta EE 10), `springdoc.api-docs.path=/v3/api-docs` `swagger-ui.path=/swagger-ui.html`, `OpenApiConfig` `OpenAPI` `info.title=Project Management System` `servers - url: /api/v1` `openapi: 3.1.0`, `GET /v3/api-docs` + `/v3/api-docs.yaml` include `GET /api/v1/health`, `GET /swagger-ui.html` 302→`index.html`, generates `docs/api/openapi-v1.yaml` via `OpenApiTest` (not manually edited)
- [BE-S002-08] Establish backend testing foundation with Testcontainers — `org.testcontainers:postgresql:1.21.3` + `junit-jupiter:1.21.3` (test), `AbstractIntegrationTest` `@Testcontainers(disabledWithoutDocker=true)` `@Container PostgreSQLContainer(\"postgres:16-alpine\")` `@DynamicPropertySource` (`spring.datasource.url/username/password`, `flyway.enabled=true`, `ddl-auto=validate`), `SmokeIT` `@SpringBootTest` proves Flyway V1 + JPA bootstrap on real DB (skips gracefully if Docker unavailable), `maven-failsafe-plugin`, H2 runtime + `application-h2.yml` (`create`, `flyway.enabled=false`) for `spring-boot:run -Dspring-boot.run.profiles=h2`, README docs

### Added (Sprint 004)
- [BE-S004-01] Auth persistence and JWT infrastructure — `users` (`id UUID PK, email unique, password_hash, created_at/updated_at`) + `refresh_tokens` (`id UUID PK, user_id FK, token_hash unique, jti unique, expires_at, revoked`) via `V2__create_users_and_refresh_tokens.sql`, `User`/`RefreshToken` entities (`@Entity @Table`, extend `BaseEntity`), `UserRepository`/`RefreshTokenRepository` (`JpaRepository`), `spring-boot-starter-security` `BCryptPasswordEncoder`, `auth/config/SeedUserInitializer` (`app.seed.email/password` from `SEED_USER_EMAIL/PASSWORD` env, not hard-coded), `app.jwt.secret` (`${JWT_SECRET:dev-secret-64-bytes…}`) `access 15m` `refresh 7d` with `jti`, `JwtService` (`io.jsonwebtoken:jjwt-api 0.12.5` `HS256`) `generateAccess/Refresh` `parse/validate` `isAccess/isRefresh` `getUserId/getJti`, `RefreshTokenService` `SHA-256 hash` `store/revoke/isValid` rotation/invalidation, `SecurityConfig` permitAll (health/docs public, real filter in BE-S004-05), no endpoints yet
- [BE-S004-02] Login endpoint (access + refresh via HttpOnly cookie) — `POST /api/v1/auth/login` accepts `{email,password}` `@NotBlank @Email` → `200 {data:{accessToken,user:{id,email}}}` + `Set-Cookie refreshToken HttpOnly Secure SameSite=Strict Path=/api/v1/auth/refresh Max-Age 7d`, BCrypt verify + `JwtService` + hashed refresh storage, `InvalidCredentialsException` → `401` RFC9457 `type https://api.example.com/problems/unauthorized`, CORS `withCredentials` (CorsConfig `allowCredentials`), CSRF via `SameSite` + `HttpOnly` + no JS access documented, OpenAPI `@Tag/@Operation`, `AuthControllerTest` 5 MockMvc tests (success/401/validation/CORS)
- [BE-S004-03] Refresh token rotation endpoint — `POST /api/v1/auth/refresh` reads `refreshToken` HttpOnly cookie (`withCredentials`), validates existence/not expired/not revoked/hash matches + JWT valid/type refresh, invalidates old, issues new `accessToken` + new `refreshToken` cookie (rotation) → `200 {data:{accessToken}}`, reuse of old → `401` ProblemDetails + chain invalidation (`deleteByUserId`), missing/invalid/expired → `401`, OpenAPI, `AuthRefreshTest` 5 MockMvc (rotation, reuse 401, missing/invalid 401, CORS) + `AuthIntegrationTest` Testcontainers 4 skipped if no Docker

### Added (Sprint 005)
- [BE-S005-01] Project persistence (entity, migration, repository) — `projects` (`id UUID PK, name required, description nullable, owner_id FK users NOT NULL, created_at/updated_at`) + `project_members` (composite PK `project_id/user_id`, FKs cascade) via `V3__create_projects_and_project_members.sql`, `Project` extends `BaseEntity` (`ManyToOne owner`, `name @NotBlank @Size(255)`), `ProjectMember` `@IdClass(ProjectMemberId)`, `ProjectRepository` + `ProjectMemberRepository` (`existsByProjectIdAndUserId`, `findByUserId`), no endpoints yet, `ProjectPersistenceTest` 4 H2 tests (persist, null description, blank-name 422-validation, membership queries)
